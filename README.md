# Data_TalentOps
Repositorio para subir las actividades de la Ruta Profesional de Datos de la plataforma TalentOps.

Los contenidos del curso están divididos en 3:
- Fundamentos de Datos y Control de Versiones
- Análisis de Datos y Estadística
- Herramientas ETL y Proyecto final

Cada carpeta de contenido contiene 4 carpetas que representan 1 semana de trabajo y en cada una de estas se encuentran los ejercicios de práctica diarios.
