# Data_TalentOps 🗂️

Este repositorio tiene como objetivo recopilar las evidencias de las actividades realizadas para la Ruta Profesional de Datos de la plataforma TalentOps.

Los contenidos del curso están divididos en 3:
- 📁 [Fundamentos de Datos y Control de Versiones](https://github.com/petite09/Data_TalentOps/tree/main/01.Fundamentos_de_Datos_y_Control_de_versiones)
- 📁 [Análisis de Datos y Estadística](https://github.com/petite09/Data_TalentOps/tree/main/02.Analisis_de_datos_y_estadistica)
- 📁 [Herramientas ETL y Proyecto final](https://github.com/petite09/Data_TalentOps/tree/main/03.Herramientas_ETL_y_Proyecto_Final)

Cada mes de la ruta de aprendizaje contiene 4 carpetas que representan 1 semana de trabajo y en cada una de estas se encuentran los ejercicios de práctica diarios.

Además, cada ejercicio práctico va acompañado de anotaciones sobre conceptos vistos a lo largo del curso, algunas recomendaciones o consideraciones a tener en cuenta para cada actividad, junto con pantallazos como evidencia de los distintos ejercicios.
